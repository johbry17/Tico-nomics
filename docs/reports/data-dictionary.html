Variables in the analytical datasets

This page documents every variable in the final analytical datasets. Variables are grouped by dataset. Units, sources, transformations, and interpretive limitations are noted where relevant.

project_name Loan-level project name IBRD Statement Text May differ slightly from Projects List name

loan_status Current loan status IBRD Statement Category As of 09/30/2026 snapshot
board_approval_date Board approval date (raw string MM/DD/YYYY) IBRD Statement Date Source: IBRD Statement field

approval_year Calendar year of board approval Derived Integer

IFC projects (data/processed/ifc_projects.csv)

Unit: One row per unique IFC project number (deduplicated from 40 disclosure rows to 30 projects).

IFC projects — variable definitions
Variable Definition Notes
project_number IFC project number Primary key
project_name IFC project name
type_desc Investment or Advisory Services
status Active / Completed / Pending
sector Full IFC sector classification code and name Granular IFC taxonomy
sector_group Simplified sector grouping Derived: Financial Services / Energy / Tourism etc.
approval_date_act Actual Approval Date Available only for 2 Advisory Services projects
projected_board_dt Projected Board Date PLANNED date, not confirmed approval
best_date Coalesce(approval_date_act, projected_board_dt) Best available date proxy
best_year Year from best_date Use with caution; projected dates only for investments
date_type Describes which date was used 'Actual (Advisory only)' or 'Projected board date (indicative)'
ifc_invest_usd_m IFC own-account investment amount in USD millions Parsed from 'Investment as Approved by The Board' text field
n_docs Number of disclosure documents for this project
is_advisory type_desc == 'Advisory Services'
is_investment type_desc == 'Investment'
is_pipeline status == 'Pending' Insulet CR (51930) — excluded from historical analysis
in_scope best_year >= 1980 & best_year <= 2025

IFC amounts are indicative and NOT comparable to IBRD sovereign loan principal. They represent IFC’s own-account investment in private entities. The investment_text field also includes syntax from the disclosure portal; amounts are extracted from the leading number.

MIGA projects (data/processed/miga_projects.csv)

Unit: One row per deduplicated project (10 projects from 12 source rows; project 3639 uses FY2003 as canonical record).

MIGA projects — variable definitions
Variable Definition Notes
project_id MIGA project identifier Integer
title Project title
sector Sector (Tourism / Banking / Power / Transportation / Manufacturing)
fiscal_year MIGA fiscal year of guarantee issuance FY = July–June; FY2008 = July 2007–June 2008
fy_label Integer copy of fiscal_year for filtering Use fiscal_year for labeling; fy_label is NOT a calendar year
gross_exposure_up_to Maximum MIGA liability under issued contracts (US$ millions) NOT a loan; NOT capital received by Costa Rica
description MIGA guarantee description From MIGA project brief
investor_country Country of origin of investor
in_scope fy_label >= 1980 & fy_label <= 2025 Based on fiscal year label; see FY convention note

Project 3639 (Grupo del Istmo de Papagayo) appeared in FY2001, FY2002, and FY2003 with escalating cumulative exposures ($16.4M, $38.3M, $81M). The FY2001 and FY2002 rows were removed; the FY2003 row ($81M) represents the most complete disclosure. Summing all three rows would overcount by approximately $136M.

US GDP deflator (data/processed/us_gdp_deflator.csv)

Unit: One row per year (1960–2025).

Variable Definition Notes
year Calendar year Integer
defl US GDP deflator index Indicator NY.GDP.DEFL.ZS from World Bank API. Base year 2020 = 100 (per API response). Annual.

Formula for converting nominal to real:

real_2025 = nominal * (defl[year==2025] / defl[year==approval_year])

2025 deflator value: 122.36 (preliminary; may be revised).
