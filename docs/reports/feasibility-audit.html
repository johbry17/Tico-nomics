1. Source files

Two JSON files were downloaded from the World Bank Projects API and stored as raw data. Neither file was modified.

world_bank_costa_rica.json 151 KB search.worldbank.org/api/v2/projects?format=json&countrycode=CR&rows=100

3. Financing fields

The API provides several financing fields:

Field Interpretation Note
totalamt World Bank IBRD commitment at approval String, comma-separated (e.g., "200,000,000"); identical to ibrdcommamt in nearly all cases
ibrdcommamt IBRD loan commitment Matches totalamt for all sampled projects
lendprojectcost Total project cost Often higher than totalamt; includes counterpart and co-financing
grantamt Grant component (rare) Present for a few projects
curr_total_commitment Current commitment (in millions) Reflects any amendments; differs from totalamt for some projects

totalamt is used throughout as the World Bank IBRD lending commitment. It should not be labeled as total project cost.

All amounts are nominal US dollars at the time of commitment. Comparing commitments across 35 years without inflation adjustment overstates the real value of older loans relative to recent ones. For exploratory purposes, nominal amounts are retained; any cross-period comparisons are treated as approximations only.

4. Sector fields

The API returns sector information in two complementary structures:

  • sector1, sector2, sector3: Named slots with Name and Percent subfields. Each gives a sector name and its percentage share of the project’s activities.
  • sector_namecode: An array of all sector assignments (may capture more than 3 sectors).
  • mjsector_namecode: An array of major sector groupings.
Sector field Projects with data (all 72) Notes
sector1 (name) 62 10 recent projects have empty names
sector2 (name) 19 Most projects have only one or two sectors
sector3 (name) 11 Rarely populated
sector1 pct > 0 62 Percentages available whenever name is available
Projects with pcts summing to ~100% ~40 Remaining have partial or missing pcts

Sector allocations: When sector percentage data is available and sums to approximately 100%, project financing is allocated proportionally across sectors. For example, a $100M project where 60% goes to Public Administration and 40% to Transportation contributes $60M and $40M respectively to sector totals. This avoids double-counting project financing.

When percentages are unavailable or do not sum correctly, projects are included in sector counts but excluded from allocated financing totals.

5. Project abstracts

Abstracts are available for 46 of 72 projects (26 missing). Abstract length ranges from 417 to 2582 characters (median: 1062).

Abstracts describe stated project objectives and intended outputs, not actual implementation or outcomes. Keyword analysis can identify recurring development themes in Bank project design but cannot assess project effectiveness.

Missing abstracts are concentrated among older and dropped/cancelled projects.

Notes:

  • GDP per capita: Annual data, full 1990–2024 coverage. Reliable for trend analysis.
  • Gini index: Annual coverage 1990–2024 thanks to Costa Rica’s continuous Encuesta de Hogares (Household Survey). Values represent income inequality at the household level. Treat year-to-year variation cautiously; focus on multi-year trends.
  • Life expectancy: Annual data, full 1990–2024 coverage. Reliable.
  • Adult literacy: Only 2 observations in the 1990–2024 window (year 2000 and 2011). Not usable for trend analysis. Excluded from visualizations.

Overall verdict: Proceed with modifications

The core project-level data is sufficient to support a meaningful exploratory analysis of World Bank lending in Costa Rica from 1990 to 2024.

Modifications relative to original scope:

  1. Time series gap: The 16 missing-date projects create an apparent gap in 2013–2019 activity. All charts note this limitation explicitly.
  2. Sector analysis limited: Only 3 sector slots captured; most recent projects lack sector data. Sector analysis is indicative, not complete.
  3. Nominal amounts only: No inflation adjustment is applied. Cross-period comparisons of dollar amounts should be treated as approximations.
  4. Adult literacy excluded: Insufficient data points.
  5. Gini treated carefully: Annual data is available, but trend interpretation should be tempered by awareness of survey-to-survey variation.

The analysis proceeds with these limitations documented throughout.
