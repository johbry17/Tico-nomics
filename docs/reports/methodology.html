Methodology

Research design, source hierarchy, and analytical decisions

Author

Bryan C. Johns

Published

November 6, 2026

1. Research design

This project examines the World Bank Group’s financing relationship with Costa Rica from 1980 to 2025. The central question is how that relationship evolved across four decades — in scale, instruments, sectoral priorities, and stated development objectives — and what the evolution reveals about the intersection of Costa Rica’s development trajectory and the World Bank Group’s changing institutional practice.

The analysis is explicitly not a causal study. It does not test whether World Bank lending caused changes in GDP, inequality, health, or other outcomes. It examines the portfolio itself and the context in which it operated.

Unit of analysis: Individual projects and loans, aggregated by year, period, and sector.

Geographic scope: Costa Rica only. Findings are not representative of the World Bank Group’s global portfolio or of developing-country experience generally.

Study period: 1980–2025 inclusive. Pre-1980 records are retained for reference but excluded from primary totals and charts. Three projects approved in 2025 are included. Records from 2026 are outside scope.

3. Project universe reconciliation

The Projects & Operations List contains 115 Costa Rica project records. The IBRD Statement contains 68 loan records for 59 unique project IDs. The WB Projects API V2 extract contains 72 project records.

Membership Count
All three sources (Projects List + API + loans) 51
Projects List + API (no loan record) 21
Projects List + loans (not in API) 8
Projects List only 35

The 43 projects in the Projects List but not in the API fall into four categories: 1. Legacy P006xxx-numbered projects not indexed in the V2 API search system (pre-2000). 2. Grants, GEF trust-fund operations, and other non-IBRD financing types. 3. Early-1990s IBRD loans not returned by the API. 4. P148435 ($420M, 2016) — the most significant missing project.

For IBRD financial analysis, only the 59 project IDs with loan records are used. Projects Board Approved but without loan records, and grants or trust funds, are excluded from financial totals.

4. Treatment of project approval dates

The V2 API extract had missing boardapprovaldate for 16 projects. A three-stage date recovery process was conducted:

Stage Method Outcome
Phase 0 V2 API extract 16 projects with NULL boardapprovaldate
Phase 1 V3 API + WB bulk Excel (downloaded 2026-10-30) 15/16 dates recovered; V3 and Excel agreed on all 15
Final Projects & Operations List as primary source Board dates used from Projects List where available

The one permanently unresolved project is P169724 (Learning for All, Dropped, $100 million planned). There is no approval date in any source for this project; it was likely never board-approved.

All recovered and original dates are compared against the Projects & Operations List. Where dates differ between sources, the Projects List is used as authoritative.

5. IBRD financial definitions

All IBRD amounts are from the IBRD Statement of Loans and Guarantees, snapshot 09/30/2026.

Term Definition
Original Principal Amount Loan amount as approved by the IBRD Board, in nominal US dollars at time of approval
Cancelled Amount Portions of the principal cancelled — unused balances at close, mid-project reductions, or full cancellation of Terminated loans
Net Principal original_principal - cancelled_amount. Represents the commitment net of cancellations. Not “money received.”
Undisbursed Amount Remaining balance not drawn, converted at end-period exchange rate
Disbursed Amount Cumulative drawdowns since inception. Not an annual flow. Cannot be assigned to approval year.
Repaid to IBRD Cumulative principal repaid
Due to IBRD Outstanding principal

Primary analytical measure

Original Principal Amount is used as the primary measure of approved lending scale. It maps cleanly to the approval year, is unambiguous (it was set at the board meeting), and allows comparison across time. Net principal is reported alongside it but not used as the primary measure for trend charts.

Real amounts use the formula: real_2025 = nominal * (defl_2025 / defl_approval_year), where defl_x is the World Bank GDP deflator value (NY.GDP.DEFL.ZS) for year x.

Cumulative disbursements and annual flows

The disbursed amounts in the IBRD Statement are cumulative balances as of 09/30/2026. They cannot be assigned to the approval year and do not represent annual disbursement flows. Annual disbursement data would require transaction-level records from the World Bank’s International Debt Statistics (IDS) or equivalent sources, which are not part of the current dataset.

Cancellations

Three loans have “Terminated” status: P006945, P006942, P006940. For these, original principal equals cancelled amount (net = 0); they were approved but the loan agreements were never signed or the loans never became effective. They are included in project counts but excluded from net principal totals.

6. Instrument classification

IBRD loan types in the Statement (CPL, FSL, NPL, SCL, SCPD) are financial-term codes, not operational instrument types. Classification as Development Policy Loan or Investment Project Financing uses the following logic, applied in 04_prepare_ibrd.R:

Classified as DPL Reason
P006919, P006922, P006923, P006927, P006952 Structural Adjustment Loans (SAL I, II, III) or SAL-era policy lending
P111926 (CAT DDO, 2008) Contingent credit line (DDO = deferred drawdown, policy-based)
P115173 (2009) “Public Finance and Competitiveness Development Policy Loan”
P171912, P174786, P177029 (2020–2023) “Fiscal and Decarbonization Management DPL”
P179861 (2023) “Second Disaster Risk Management Development Policy Loan”
P181372 (2024) “Social Risk Management DPL DDO”
P508347 (2025) “Fiscal Management and Green Growth” — confirmed DPL in project description

All other projects are classified as Investment Project Financing. The NPL code (one loan) maps directly to DPL/adjustment.

Note: Several 1980s-era projects (P006933 Technical Assistance, P006924 Atlantic Agriculture, P006926 Transport Sector, P006938 Basic Education, P006941 Water Supply, P006954 Health Sector) had supplemental SCPD companion loans — a “policy tranche” common in the SAL era — but are classified as Investment Project Financing because the primary CPL loan funded investment activity. Only the pure SAL/structural adjustment operations are classified as DPL.

7. Sector classification

Sector information comes from two sources: 1. WB Projects API V2 (sector1, sector2, sector3 with name and percentage) 2. Projects & Operations List (Sector 1, 2, 3 — name only, no percentages)

API sector data is preferred; Projects List names supplement where API is unavailable.

Where sector percentages are available, project financing is allocated proportionally across sectors. For example, a $100M project with Sector 1 at 60% and Sector 2 at 40% contributes $60M and $40M respectively to sector totals. This avoids double-counting.

Limitation: Sector data is available for 22 of 35 in-scope IBRD projects. The 2020–2025 DPL series lacks sector percentage data in the API, significantly understating the financial weight of those operations in the sector analysis.

Ten broad sector groups are defined in functions.R:group_sector().

8. Inflation adjustment

Primary index: US GDP deflator, indicator NY.GDP.DEFL.ZS, retrieved from World Bank API (api.worldbank.org/v2/country/US/indicator/NY.GDP.DEFL.ZS).

Base year: 2020 = 100 (as returned by the API).

Coverage: 1960–2025, no missing years.

Why GDP deflator (not CPI): CPI measures consumer price changes affecting US households; the GDP deflator measures price changes across all US-produced final goods and services. For comparing the real scale of historical dollar-denominated financial commitments, the GDP deflator is more appropriate.

Limitations: - Neither index measures the local purchasing power of lending in Costa Rica. - The 2025 deflator value is preliminary and may be revised in future WB data vintages. - A $100M loan in 1985 purchased different quantities of Costa Rican infrastructure than $100M in 2020.

Validation: The 1980→2025 multiplier is approximately 3.275, consistent with the Phase 1 reference check (~$328M in 2025 USD per $100M in 1980).

9. IFC methodology

IFC investment amounts represent IFC’s own-account investment in private entities and are fundamentally different from IBRD sovereign loan principal. They are never combined with IBRD figures.

Date caveat: Only 2 IFC projects (Advisory Services) have actual Approval Date values. All Investment projects show Projected Board Date — a planned date, not an actual approval confirmation. Year assignments from IFC data are approximate and should not be used for precise annual time-series claims.

Amount parsing: The Investment as Approved by The Board field in the IFC Excel contains text such as “15.0 million (USD)…”. Investment amounts are extracted by parsing the leading number.

Deduplication: The source file contains 40 rows for 30 unique project numbers (10 projects have multiple disclosure documents). The final dataset uses one row per project number, taking the first non-missing value for each field.

Known issues documented in 05_prepare_ifc.R: BAC CR Green ($200M, 2025), Coopenae ($15M, 2011), Aeropuerto Juan Santamaría ($35M, 2000), Corporacion Supermercados Unidos ($40M, multi-country), Insulet CR ($97M, pipeline/excluded).

10. MIGA methodology

MIGA Gross Exposure Up to represents the maximum possible MIGA liability under issued guarantee contracts, not a loan or capital transfer.

Fiscal year: MIGA uses World Bank fiscal years (July 1 – June 30). FY2008 = July 2007 – June 2008.

Deduplication: Project 3639 (Grupo del Istmo de Papagayo) appears three times in the source data (FY2001, FY2002, FY2003) with amounts of $16.4M, $38.3M, and $81M respectively. These represent successive disclosure events for the same development, not three independent guarantees. The FY2001 and FY2002 rows are removed; FY2003 ($81M) is used as the canonical record representing peak exposure. Summing all three rows would overstate by ~$136M.

11. IDA context

Costa Rica’s last IDA credit was in FY1962 (source: World Bank IDA Graduates page). The 1980–2025 analysis is entirely IBRD. The IBRD Statement contains no IDA transactions for Costa Rica.

12. Calendar year vs fiscal year conventions

IBRD and the Projects & Operations List use calendar-year board approval dates. IFC and MIGA use World Bank fiscal years (July–June). This project uses calendar years for the primary IBRD analysis. IFC and MIGA dates are labelled as approximate or fiscal-year as appropriate.

14. Reproducibility

The complete analysis can be rebuilt from raw source files.

Prerequisites: R ≥ 4.4, Quarto ≥ 1.4, R packages listed in R/00_setup.R.

Pipeline (run in order from project root):

source("R/01_import_sources.R") # documentation only
source("R/02_prepare_wdi.R")    # deflator and WDI (requires internet)
source("R/03_reconcile_projects.R")
source("R/04_prepare_ibrd.R")
source("R/05_prepare_ifc.R")
source("R/06_prepare_miga.R")
source("R/07_analysis.R")
source("R/08_visualizations.R")
source("R/09_validation.R")     # all checks should pass

Then render the site:

quarto render

Scripts requiring internet access: 02_prepare_wdi.R (World Bank API calls for deflator and WDI indicators). All other scripts read only from data/raw/ or earlier pipeline outputs in data/processed/.

Raw files in data/raw/ must be preserved unchanged. The archive/ directory contains historical exploratory scripts from Phase 0 and Phase 1; they are not part of the active pipeline.
